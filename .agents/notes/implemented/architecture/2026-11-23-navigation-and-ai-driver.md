# Agent Note: 导航路径查询与可插拔 AI 驾驶员

Status: implemented

## Problem

路线变多后，玩家需要在地图上看见终点与剩余路线；同一份路线还要能交给自动驾驶，而不是让 UI 与驾驶各自查询。LLM 自动驾驶的延迟、费用与输出不可控，不能成为游戏可玩性的单点依赖，也不能把密钥写进仓库。

## Decision

新增只读适配层 `src/nav/road-adapter.js`，把现有环形道路或有序多段路网统一成 `{ length, width, sample(t), nearest(x,z) }`；道路生成仍归 `world/route.js`，适配层不修改任何道路对象。`src/nav/path.js` 提供纯函数 `planPath(network, from, to)`，输出带累计距离与航向的有序路径点；`src/nav/navigation.js` 缓存目的地与查询结果，只有目的地变化或车辆倒车退出规划区才重建。小地图高亮、`src/ai/local-planner.js` 与 LLM 观测都消费同一个 `PathPlan`，不存在第二份路线查询。

环线坐标需要结合行驶历史展开：`pathProgress` 默认选择离规划区间最近的一圈，实时导航传入上次累计进度，从而区分长路线前进与短距离倒车。每帧仅保存一个累计距离，跨半圈、跨零点均保持路径对象不变；相邻观测移动须小于半圈，地图传送由既有入口清空导航。

驾驶员契约是 `observation → { throttle, brake, steer }`（油门/刹车 0..1，转向 -1..1，正数向右）。本地规划器每帧都计算，是可玩性的基线；`src/ai/llm-driver.js` 只在显式配置后发请求，带超时、最小间隔、在途去重、指令 TTL、失败指数退避和容错 JSON 解析；`src/ai/autopilot.js` 只在 LLM 指令新鲜且合法时替换本地指令，距终点 8 m 内强制本地制动，任何手动输入立即退出自动驾驶。默认配置关闭且不发请求，LLM 不可用时车辆继续由本地规划器驾驶。

每个 LLM 请求独立持有控制器、定时器和身份，完成时仅当前请求能写入结果。取消或换配置使在途请求失效并清空指令；失败也立即清空指令，旧请求不能清除新请求的状态。TTL 从发送观测时刻计算，过慢的回复不会获得一段新的有效期。已出现但非法的控制字段使整条指令失效，保留数字字符串、别名和围栏等格式容错。

导航采用单行道语义：路径总是沿 `t` 增加方向前进，终点在后方时绕环线一整圈；暂不建模掉头与分叉拓扑。多段路网按数组顺序线性化，等路网工作流定义连接关系后可在适配层之上增加图搜索，`path.js` 的输出格式不变。

配置按 `localStorage['pixel-horizon-ai']` → 页面加载前的 `window.__HORIZON_AI__` → 运行时 `__horizon.autopilot.configure()` 的顺序覆盖，页面显式禁用优先于存储设置；仓库中没有任何密钥或私有端点，`status()` 只报告端点主机名与模型名。

## Alternatives considered

- 在 `ui.js` 内直接计算高亮路线：实现最快，但 AI 驾驶会复制一份查询，路线变多后必然分叉；未采用。
- 重写路网为图结构并在本工作流内做 A*/Dijkstra：当前路网是单环，且另一工作流正在扩充路网数据；在本工作流重写会与其冲突。采用只读适配层，把拓扑留给路网工作流。
- 让 LLM 输出控制并作为唯一驾驶员：接口最简单，但延迟与非法输出会让车辆失控；未采用。LLM 是可选驾驶员，本地规划器兜底。
- 只按起点计算最短有符号弧长：无需状态，但超过半圈的正常前进会被误判为倒车；采用累计进度展开，保留真实倒车重规划。
- 只调用 `AbortController.abort()`，或从回复时刻开始 TTL：代码较少，但读取响应体期间的取消和迟到回复仍可能污染驾驶状态；以请求身份隔离结果，并把推理时延计入有效期。
- 在服务端代理 LLM：安全性更好，但本项目是可双击打开的离线单页游戏，没有服务端；文档明确建议本地模型或自建代理，代码不内置任何端点。

## Consequences

地图、AI 驾驶与 LLM 观测共享同一份路径，改变高亮不会改变驾驶路线，反之亦然。默认离线可玩，不配置 LLM 时零网络请求，独立 HTML 仍可直接双击运行；`verify:standalone` 与 `verify:navigation` 分别证明这两点。

代价是导航只支持“沿当前方向前进”的单行语义，终点在身后会绕行整圈；分叉/路口需要路网工作流提供连接关系后再补图搜索。LLM 在浏览器直连时密钥对页面可见，这是本项目的部署边界，文档已标注。

`tests/navigation.test.js` 覆盖长路线、跨零点、近整圈倒车与路径复用；`tests/ai.test.js` 覆盖约 5.97 km 本地驾驶到达和 LLM 取消、换配置、错误、过期。浏览器验收通过地图按钮启动自动驾驶并验证人工接管和到站停车。终点保护保证本地制动优先，停车距离仍取决于接管速度。
