# Agent Note: 常规左舵与驾驶仪表状态

Status: implemented

## Problem

原型把世界+X当成了驾驶者右侧。车辆前方使用+Z、上方使用+Y时，追尾相机朝+Z看，+X投影到屏幕左侧。因此原型D键实际左转，cockpit.x=-.325也落在右侧驾驶位。原测试只断言世界坐标x增大，未检验玩家在真实相机中看到的方向。

原仪表和引擎声按车速分段制造挡位与转速，无法呈现自动换挡的机械状态。

## Decision

动作层以steer正值表示驾驶者右转。输入、驾驶、巡航与车轮共同遵守此约定：驾驶yaw采用负号，巡航航向误差反号，前轮视觉Y旋转为负；车头+Z时左侧驾驶位位于本地+X。

`input.js`统一键盘和触屏动作；`drive.js`是rpm、gear、fuel、coolant、odometer的唯一状态来源。七速自动变速根据轮速与齿比选挡，升挡有转速回落和0.38秒换挡防抖。车速、转速、挡位、油量、温度和里程同时传给车内仪表、HUD与声音。重置车辆保留旅程里程与燃油，只将挡位与发动机恢复静止状态。

## Alternatives considered

只交换A/D按键改动最小，但会让键盘、触屏、前轮与巡航各有相反约定，未采用。

继续按速度段生成假转速和挡位实现简单，但不能表现升挡回落，也会令车内外仪表与音效不一致，改由驾驶模型输出。

## Consequences

Three.js相机真实投影成为左右方向的回归依据。单测同时覆盖前进、倒车、数字输入相消、高速转向回正、自动挡与完整环线巡航。车内仪表的清晰程度、刻度位置与指针运动仍需实际驾驶舱截图和加减速操作验收，数值通过不能代替视觉质量。

此决定延续[观景驾驶状态边界](../../implemented/architecture/2026-11-21-scenic-drive.md)的单一驾驶状态归属，修正其初版未明确的局部坐标语义。
