# PIXEL HORIZON · 地平线

开着一辆红色 AMG ONE 风格跑车，沿着山海公路自由兜风。默认没有倒计时；可以自己驾驶，也可以开启观光巡航，切换视角看风景。

车辆为左侧驾驶位：A / ← 向左，D / → 向右，前轮与方向盘同步。驾驶舱具有动态转速指针、车速、七速自动挡、油量、水温、里程、换挡灯和转向灯。升挡时转速回落；仪表、HUD 与引擎声读取同一套机械状态。

**直接试玩：双击项目根目录的 `Pixel-Horizon.html`，用 Chrome 或 Edge 打开。** 场景、车模、字体和声音都在本地，游戏运行不需要联网。

开发时运行：

```sh
npm install
npm run dev
```

终端会显示本地地址。构建与预览：

```sh
npm run build
npm run preview
```

构建生成 `dist/` 网站与可独立打开的 `Pixel-Horizon.html`。

| 操作 | 按键 |
| --- | --- |
| 加速、转向 | WASD 或方向键 |
| 刹车、倒车 | S / ↓；停稳后松开再按即可倒车 |
| 手刹 | 空格 |
| 切换视角 | C：追尾 → 引擎盖 → 驾驶舱 → 高位追踪 |
| 观光巡航 | F；转向或刹车接管，油门可暂时提速 |
| 地图、六景区直达 | M |
| 观景摄影 | P；拖动鼠标环视，滚轮缩放 |
| 午后 / 日落 | T |
| 左 / 右转向灯 | Q / E，再按关闭，完成转向回正后自动取消 |
| 隐藏驾驶界面 | H |
| 回到公路 | R |
| 暂停 / 继续 | Esc |

触屏设备显示方向、加速与刹车按钮。桌面浏览器为主要体验平台；触屏布局和按钮已通过浏览器模拟检查。

环线长约 **7.46 km**，串起晴湾小镇、灯塔海岸、金穗原野、枫色河谷、松影镜湖与云上垭口。按 M 可直接去下一处景色，地图右下也可以开启一场三位电脑对手参加的海岸短程赛。

本版采用 Three.js 真 3D 场景、固定步长驾驶、程序化原创曲面车辆与风景、像素纹理与色阶后期。外景保留像素观感，驾驶舱提高渲染精度以看清刻度和指针。分叉枝叶、细节建筑、石桥和码头配合真实阴影、道路骨料、地表岩层和分层水面。车辆以用户提供的 AMG ONE 图片为造型参考；驾驶使用适合轻松游玩的简化模型。

检查：

```sh
npm test
npm run build
npm run preview -- --port 5174
```

在另一个终端运行 `npm run verify:browser`，使用已安装的 Chrome 实测驾驶、四视角、巡航、地图、摄影、暂停、短程比赛、竖屏与触控。报告为 `shots/playability-results.json`，实际截图保存在 `shots/horizon-*.png`。`npm run verify:standalone` 直接打开本地独立 HTML，检查启动、驾驶以及没有外部网络请求；本版已通过这些检查。

`npm run verify:instruments` 在实际驾驶中核对车内仪表与驾驶状态，并保存静止、加速和日落画面。机械逻辑测试也覆盖左右真实相机投影、倒车、高速回正、自动换挡、温度与燃油、转向灯和完整环线。`npm run verify:memory` 在真实 Chrome 中驾驶 60 秒并连续换车 12 次，检查 JS 堆与 WebGL 资源不随换车增长。

> ⚠️ 验证脚本里**不要**把 Three.js 对象直接传给 `assert.equal` / `assert.deepEqual`：断言失败时 Node 会打印整张场景图（循环引用、全部顶点与纹理），单进程几十秒可涨到 10 GB 以上并冻结机器。事故复盘与排查清单见 [Node 断言打印 Three.js 场景图导致内存暴涨](.agents/notes/implemented/testing/2026-11-22-node-assert-scene-graph-memory.md)。
