# PIXEL HORIZON · 地平线

开着一辆红色 AMG ONE 风格跑车，沿着山海公路自由兜风。默认没有倒计时；可以自己驾驶，也可以开启观光巡航，切换视角看风景。

车辆为左侧驾驶位：A / ← 向左，D / → 向右，前轮与方向盘同步。驾驶舱具有动态转速指针、车速、七速自动挡、油量、水温、里程、换挡灯和转向灯。升挡时转速回落；仪表、HUD 与引擎声读取同一套机械状态。

**直接试玩：双击项目根目录的 `Pixel-Horizon.html`，用 Chrome 或 Edge 打开。** 场景、车模、字体和声音都在本地，游戏运行不需要联网。

开发时运行：

```sh
npm install
npm run dev
```

终端会显示本地地址。构建与预览：

```sh
npm run build
npm run preview
```

构建生成 `dist/` 网站与可独立打开的 `Pixel-Horizon.html`。

触屏设备显示方向、加速与刹车按钮。桌面浏览器为主要体验平台；触屏布局和按钮已通过浏览器模拟检查。

环线主线长约 **7.46 km**，串起晴湾小镇、灯塔海岸、金穗原野、枫色河谷、松影镜湖与云上垭口。主线之外还有 **10 条道路**（8 条次级公路、2 条碎石林道），合计约 **10.55 km**，组成约 **18.0 km** 的可行驶路网。10 处外环入口与 7 个内部节点把捷径、S 弯、盘山路和高低差路段连在一起；内部道路通过中央十字路口互通，东西之间可以穿过地图中央，镜湖也有跨水桥接往南鞍。

大地图和小地图显示全部真实道路，实线为公路，暖色虚线为碎石林道。按 M 可以选择六处景区直达，地图右下也可以开启三位电脑对手参加的海岸短程赛。观光巡航沿当前道路的正向前进，在内部路线端头换路时可手动转向接管。

公路上还有民用车辆：它们按右车道与对向车道行驶，会跟车、转弯减速；玩家从后方快速接近时，同向车会借对向车道让行。车流与玩家共享车辆模型，只更换涂装；NPC 不会穿过玩家，比赛期间自动暂停并在结束后恢复。按 **V** 可随时关闭或开启。数量与速度可在控制台调整：`__horizon.traffic.configure({ count: 12 })` 或 `{ density: 1.5 }`（辆/公里，默认 3，约 22 辆）。

指定终点后，小地图与大地图会标记终点并高亮从当前位置到终点的路线；按 B 由本地规划器沿同一条路线自动驾驶，抵达后自动停车。导航终点位于主线六处景区；支线路网供自由驾驶与观光巡航，若从支线出发，导航按最近主线位置计算。自动驾驶的驾驶员接口是可插拔的：可选接入 OpenAI 兼容或 Ollama 兼容的 LLM 后端，默认关闭、不配置就不联网；超时、非法输出或服务不可用时自动回退本地规划器。配置示例、请求协议、时延/费用与安全边界见 [导航与 AI 自动驾驶](docs/ai-autopilot.md)。

本版采用 Three.js 真 3D 场景、固定步长驾驶、程序化原创曲面车辆与风景、像素纹理与色阶后期。外景保留像素观感，驾驶舱提高渲染精度以看清刻度和指针。分叉枝叶、细节建筑、石桥和码头配合真实阴影、道路骨料、地表岩层和分层水面。车辆以用户提供的 AMG ONE 图片为造型参考；驾驶使用适合轻松游玩的简化模型。

检查：

```sh
npm test
npm run build
npm run preview -- --port 5174
```

在另一个终端运行 `npm run verify:browser`，使用已安装的 Chrome 实测驾驶、四视角、巡航、地图、摄影、暂停、短程比赛、竖屏与触控。报告为 `shots/playability-results.json`，实际截图保存在 `shots/horizon-*.png`。`npm run verify:standalone` 直接打开本地独立 HTML，检查启动、驾驶以及没有外部网络请求；本版已通过这些检查。`npm run verify:navigation` 验证地图设终点、小地图/大地图高亮、本地自动驾驶、人工接管、抵达停车，以及 LLM 端点正常与断开时的接管和回退（使用本地 mock 端点，不访问外网）。

`npm run verify:instruments` 在实际驾驶中核对车内仪表与驾驶状态，并保存静止、加速和日落画面。机械逻辑测试也覆盖左右真实相机投影、倒车、高速回正、自动换挡、温度与燃油、转向灯和完整环线。`npm run verify:memory` 在真实 Chrome 中驾驶 60 秒并连续换车 12 次，检查 JS 堆与 WebGL 资源不随换车增长。`npm run verify:traffic` 在真实车流中驾驶、高速逼近同向车并检查道路坐标级重叠，同时验证 V 开关、数量/密度配置与固定相机下的 draw call 开销；结果写入 `shots/traffic/traffic-results.json`，截图保存在 `shots/traffic/`。

`HORIZON_URL=http://127.0.0.1:5174/ npm run verify:network` 检查两种地图上的全部支路、景区直达、竖屏布局，并实际驶过中央路口与湖谷桥；截图与结果保存在 `shots/network/`。`HORIZON_URL` 也可设为独立 HTML 的 `file://` 地址。路网单测覆盖内部连通、路口转弯、坡度和桥下净空；实际地形三角形的射线检查约需一分钟。

> ⚠️ 验证脚本里**不要**把 Three.js 对象直接传给 `assert.equal` / `assert.deepEqual`：断言失败时 Node 会打印整张场景图（循环引用、全部顶点与纹理），单进程几十秒可涨到 10 GB 以上并冻结机器。事故复盘与排查清单见 [Node 断言打印 Three.js 场景图导致内存暴涨](.agents/notes/implemented/testing/2026-11-22-node-assert-scene-graph-memory.md)。
