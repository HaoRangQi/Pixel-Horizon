# 精细山海景物

所有网格、贴图、字体图案和配色均为本项目原创程序化制作。运行时无网络、图片下载或 Canvas 依赖；DataTexture 可在 Node 中构建。米为世界单位，正 Y 向上。

视觉方向为自然轮廓、暖色石灰墙、陶瓦、风化木作与可分辨的枝叶。近景保留实际结构，像素化由游戏主渲染器统一处理。暖红/金色落叶林只集中在秋谷，沿海树木以橄榄绿为主，镜湖与高山区使用松针结构。

| 家族 | 源码与细节 | 运行时策略 |
| --- | --- | --- |
| 阔叶树与松树 | `vegetation.js`：三组自然分叉树干，枝端多方向叶簇；松树为逐层放射枝条与松针卡片 | 共用模板，近/远 LOD；200m 空间分块；410m 切换，1650m 裁剪 |
| 路旁生态 | `vegetation.js`：多叶草束、野花、变形石块、秋季落叶 | 300m 分块可见距离；小物无阴影；紧邻道路石块尺寸受控 |
| 小镇与农舍 | `architecture.js`：灰泥/木墙、石基、灰泥山墙、挑檐底板、瓦面、雨槽、排水管、烟囱、窗框百叶、门与台阶、阳台、花箱、店招、遮阳篷、咖啡桌椅 | 共用盒体/屋顶几何，实例颜色；以完整建筑尺度装配 |
| 田野 | `architecture.js`：连续金色田块、田埂、收割条纹/轮辙、近处成簇麦穗、双横栏篱笆、捆扎草垛 | 复用实际地形表面的位置与平滑法线，抬高12cm；实例麦穗300m裁剪 |
| 灯塔 | `landmarks.js`：带底座与饰线的渐缩塔身、玻璃灯室、灯芯、金属窗柱、环形平台栏杆、铜瓦顶、避雷针、守塔人小屋 | 原位置重制，32边塔身；无新增灯光 |
| 老石桥 | `landmarks.js`：三个真实贯通拱洞、独立楔形拱石、桥墩、分水鼻、扶壁、石栏与压顶 | 挤出拱廊配合共享小构件，路面查询契约保留 |
| 码头与船 | `landmarks.js`：逐片木板、缝隙、纵梁、木桩、绳栏、系缆件、接岸扶手坡道、曲面船壳与横座板 | 湖码头从 `landscape.height` 寻找实际水边，水位由 `landscape.lake.y` 提供 |

| 观景设施 | `furniture.js`：有截面的金属护栏、反光片、灯柱、灯笼、可读路牌、石铺地、木长椅、凉架、望远镜、图牌、垃圾桶 | 木/金属/石材共享实例；镜湖护栏为坡道留出入口 |

程序贴图包括灰泥、石砌、木纹、树皮、陶瓦、阔叶簇与针叶簇。色彩图均为 sRGB；颜色贴图使用近邻放大和 mipmap 缩小。叶卡用 alpha test，不透明排序，影子为单面，少量按实例色调的透光项使背光叶片保持色彩。

`addScenery(scene, route, landscape)` 仍返回 `{ update(time) }`，额外的 `stats` 仅供检查。接口不拥有道路、地形、天空、水面、灯光、车辆或相机。

独立视觉入口：开发服务器下打开 `/src/world/scenery/preview.html?pose=coast`。可用镜位 `town/coast/fields/valley/lake/summit/lighthouse/bridge/shop/tree/dock`。`review/final-*.png` 为真实 Chrome WebGL 截图；`review/final-results.json` 记录同次场景、调用量和帧间隔。预览使用主世界和户外 IBL，未套主游戏像素后期，用来检查几何和材质本身。
